# Google Sans

Source: https://github.com/google/fonts/tree/main/ofl/googlesans
Upstream project: https://github.com/googlefonts/googlesans

The regular and italic variable fonts are bundled as WOFF2 under the included SIL Open Font License. The upstream trademark notice is included as well.

These web files retain Latin and Latin Extended characters, common punctuation, currencies and arrows, and all OpenType layout features. Other scripts use the system fallback fonts. Weight (400–700), optical size (17–18) and grade (−50–200) axes are retained.

Only the regular font is preloaded; italic loads when a screen uses it.
